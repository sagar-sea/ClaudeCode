# AWS Agent Registry: The App Store for Enterprise Agents

**Created:** 2026-05-12
**Last Updated:** 2026-05-12 19:02
**Format:** LinkedIn Post

---

AWS just launched Agent Registry.

And it solves the problem you didn't know you had: **your agents are invisible to each other.**

Your DevOps team built a deployment agent in Kiro last month. Your data team just spent two weeks rebuilding the exact same thing. Because they had no way to discover it existed.

**This is agent sprawl. And it's costing you weeks of engineering time.**

**What Agent Registry does:**

AWS Agent Registry (launched April 9) is a private catalog where your organization's agents, MCP servers, and tools live in one searchable place.

Search for agents by capability. Publish once, reuse everywhere. Approval workflows before agents go live. IAM-controlled access. Agents can even discover other agents programmatically.

**The Kiro workflow:**

Build an agent in Kiro → Publish to AWS Agent Registry → Teams discover it via search → Invoke it from their own workflows.

Your agent becomes a reusable building block.

**Why this matters:**

In 2015, we had container sprawl before Kubernetes.  
In 2026, we have agent sprawl before registries.

The team that builds a reusable agent library now ships 10x faster than the team rebuilding from scratch every sprint.

**One question:**

Where do your agents live after you deploy them?

If you don't know, you need a registry.
